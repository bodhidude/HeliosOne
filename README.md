# Helios 1 Space Weather Dashboard

Displays current space weather metrics when app is loaded and sends that data to an LLM to deliver a summary. 
LLM interface is using Andrew Ng's Aisuite and the app has a provider/model selector. Can run on a local LLM via Ollama or a provider LLM such as OpenAI, Anthropic or Google. API keys can be added where needed.
